# README 宣传横幅

`gamehall-banner.svg` 是可编辑源稿，`gamehall-banner.png` 是 GitHub README 使用的 1600×640 导出图。

图形沿用本站原创切面宝石、棋盘和扑克牌风格；宝石轮廓与配色取自 `GemMark`，不使用桌游官方美术。源稿保留文本，中文字体优先使用 Microsoft YaHei，其次 Noto Sans CJK SC；导出时须安装其中一种，避免文字缺失。

修改后使用支持 SVG 的绘图工具按原始 1600×640 尺寸导出 PNG，同步提交源稿与导出图。检查四款游戏名称与人数、中文无缺字、图形无裁切，并在 800×320 缩略尺寸复核可读性。README 使用相对路径，现有网站 `og.png` 保持独立。
